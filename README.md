# Tuoz1 Companion

[Tuoz1 Bot](https://tuoz1bot.com/) 的客户端插件。运行在你自己的电脑上，读取英雄联盟客户端的本地接口（LCU），
在每局游戏结束后把战绩发送给 Discord 机器人，让 **海克斯大乱斗** 等 Riot 公开 API 拿不到的模式也能正常播报、评分。

只依赖 Python 标准库，没有任何第三方包。不会修改游戏，不会读取账号密码。

## 下载

最新版本： **[Tuoz1Companion.exe](../../releases/latest/download/Tuoz1Companion.exe)**

## 使用方法

1. 在 Discord 里先 `/bind` 绑定账号，再输入 `/companion_token`，机器人会私下回复 **令牌**。
2. 双击运行 `Tuoz1Companion.exe`，按提示粘贴令牌，只需输入一次（保存在配置文件里，位置见下面的「配置文件在哪」）。
   机器人地址已经内置在插件里，不需要也不能自己填。
3. 打游戏时保持插件窗口开着。打完一局后，插件会等客户端生成战绩（通常几十秒），然后自动上报。
4. 和平时一样，待在语音频道里机器人才会播报。打完时不在语音也没关系，30 分钟内进语音会自动补播。

程序没有数字签名，Windows 可能提示"未知发布者"，点"仍要运行"即可。不放心的话可以直接用源码运行：

```bash
python tuoz1_companion.py
```

需要 Python 3.10 或更新版本。插件本身只用标准库；想让海克斯三选一在本机认字（更快，见下面），再装两个库：

```bash
pip install numpy onnxruntime
```

不装也能用，卡片标题会交给机器人认。

## 窗口、英雄联盟启动和简中汉化（v1.7.0）

连上机器人以后会打开一个小窗口，黑色命令行窗口自动藏起来（点窗口右上角「完整日志」再显示，再点收起）。关掉小窗口就是退出插件。

- **英雄联盟，启动！**：直接打开英雄联盟，不用再去点 Riot 客户端。客户端已经开着时变成「切到游戏大厅」，对局中显示「对局中」。
- **简中汉化（文字 + 语音）**：勾上以后，游戏的文字和语音换成简体中文。原理是把 Riot 的语言设置
  `C:\ProgramData\Riot Games\Metadata\league_of_legends.live\league_of_legends.live.product_settings.yaml`
  里的 `locale` 改成 `zh_CN`（第一次改之前在同目录备份一份 `.tuoz1.bak`）。v1.9.7 起还会把 `zh_CN` 加进同一个文件里的
  `available_locales` 名单、把这个文件设成只读：不这样的话 Riot 客户端每次启动都把语言改回去，简体中文的语言包就得每次重新下载。
  第一次用 Riot 客户端会提示下载语音包，点更新就行。取消勾选会恢复成原来的语言、名单和可写状态。
  有的电脑上只读拦不住 Riot 客户端，它每次启动照样把这个文件还原。所以 v1.12.1 起插件还盯着这个文件所在的文件夹，
  一被改回去就马上改回来（不到 0.03 秒），赶在它开始换语言包之前；这种情况日志里会说一次「只读拦不住」。
  如果每次重开 Riot 客户端还是要重新更新语言包，可以换一种不设只读的做法试试：在 `companion_config.json` 里加一行
  `"zh_locale_mode": "watch"`（文件保持可写，只管被改回去时马上改回来，和 LOLauncher 是同一个思路），然后重开插件。
  客户端开着的时候改，要重开一次客户端才生效。
- **自动接受对局**（v1.7.5）：找到对局弹出确认框时马上替你点「接受」（用客户端自己的接口，和手点一样）。已经自己点了拒绝的不动；默认关闭，勾上后记住。

- **海克斯助手**（v1.8.0）：海克斯大乱斗里三选一出来时，每张卡片上方会自动出现一条标注：这个海克斯对你这局的英雄是什么梯队（S / A / B…）、总排第几、在同稀有度里排第几，推荐的那张描边变亮并带「推荐」。不用按任何键，卡片出来大约 1 秒后标上，重掷换了卡会跟着更新，选完自己消失。
  - 游戏要用**无边框**（或窗口）模式，独占全屏下截不到卡片、标注也盖不上去。插件发现游戏设成了全屏，会通过客户端自动改成无边框（下一局生效）；不想让它改，在 `companion_config.json` 里加一行 `"aram_borderless": false`。
  - 自动没出来时可以按 **F6** 手动认一次。只在海克斯大乱斗对局中占用 F6；想换键，在 `companion_config.json` 里加一行 `"aram_hotkey": "F9"`（F1–F12）。
  - 中文和英文的卡片都认（没开简中汉化也能用）。排名优先用你这个英雄的数据，这个英雄没有数据的海克斯显示「全英雄第几」。
  - （v1.9.1）别的语言的客户端：海克斯在不同地区是不同的译名（马来西亚简体的「钝击」就是大陆的「大力」）。插件会从你自己的客户端里读出当前语言的海克斯名字，照这套叫法来认，标注上显示的也是这套叫法。马来西亚简体全部能认；台湾繁体大部分能认，少数含生僻繁体字的名字识别模型读不出来；韩文、日文认不了。认不了的可以打开「简中汉化」。
  - （v1.8.2）标注第一行是认出来的海克斯名字，可以和卡片对一眼。下面一行小字：排名、这张在你这个英雄身上的胜率、比这个英雄的平均胜率高还是低多少、有多少场数据；场次太少的会标「样本少」。这个英雄没有这张的数据时用全英雄的统计，会写「全英雄第几」。
  - （v1.8.2）**陷阱**：选的人不少、拿了以后胜率却比平均低一截的，描边和角标是红色的「陷阱」。**天胡**：这张和另一张一起拿胜率特别高的，多一行金字写着配哪张、组合胜率和场次。
  - 属性碎片这类不是海克斯的三选一不会标注；手动按 F6 时会提示「这三张不是海克斯」。
  - **不是整局都在截图**：插件从游戏的本地只读接口读你的等级和死没死，只在卡片可能出现的时候才截图去找：开局第一次；你死着，到复活后半分钟；刚升到解锁的那一级（7、11、15 级，「世界赛」嘉宾还有 21 级）；标注过的卡片刚消失的一分钟内（可能只是收起来了，或者接着选攒下的下一个）。别的时候完全不截图。「KDA」嘉宾额外的那一次是死亡后出现的，也算在内。按着 Tab 看计分板时不识别。读不到等级时照老办法一直找；手动按 F6 随时可用。
  - **选人梯队和英雄攻略**：海克斯大乱斗选人时，客户端右边会贴出一条侧栏：你手上英雄的梯队和胜率、候选席上每个英雄的梯队（按强到弱排，比你手上强的会亮起来）、这个英雄的技能加点、召唤师技能、出装和最强的几个海克斯。换英雄会跟着变。你的英雄和候选席上每个英雄前面都带头像（客户端自带的图，不联网）。
  - **AI 开局攻略**：读条时同一条侧栏贴在游戏窗口右边（游戏占满屏幕时在画面右侧），最上面多一段 AI 按这局双方阵容写的建议（对面阵容、出装调整、打法、最大威胁），游戏开始 40 秒后自己收起。不想要 AI 这一段，在 `companion_config.json` 里加一行 `"aram_ai_guide": false`。
  - （v1.8.2）**对局里的侧栏按阶段换页**，每个时刻只显示当下用得上的一页，所以每页都短，游戏占满屏幕也放得下：读条和刚开局是「AI 建议 + 出装 + 加点」；三选一出来时自动换成「天胡组合、陷阱、最强海克斯」，之后每一轮三选一也会自己出来，选完收起；随时按住 Tab（看计分板的那个键）是「出装」：核心、出门、后续，还有另一套流派，松开就收起。装备和海克斯都带图标（客户端自带的图，不联网）。
  - 默认开启，不想用就取消勾选。点这一行右边的「细项」可以单独开关：海克斯选择推荐（关掉后只能按 F6 手动识别）、攻略侧栏、AI 开局攻略。`--no-gui` 模式下没有这个功能。

- **十人战绩**（v1.8.0）：读条界面上，每张英雄卡片的底边贴一条小标签：这个人近 20 局的胜率和 KDA，一起开黑的标「双排 / 三排」，再按 KDA 评一个「上等马 / 中等马 / 下等马 / 牛马」（大乱斗类的对局按 4.5、3.2、2.2 三条线，其它模式按 3.5、2.5、1.8），一队里近期打得最凶的那个是「精品上等马」。读条结束自己消失。不分模式，5 对 5 的对局都有；不想要，在 `companion_config.json` 里加一行 `"player_stats": false`。

- **查别人的战绩是怎么查的**（v1.10.0）：十人战绩和开局情报要查对局里其他人的近期战绩。插件直接去问 Riot 的战绩服务器：
  十个人、每人 20 局，三秒左右。用的是你客户端里当前登录的通行证，只发给 Riot 自己的服务器（`*.pp.sgp.pvp.net`），
  不经过机器人，不存盘，不进日志。这不是 Riot 公开的接口，哪天走不通了，插件自己退回让客户端代查
  （和你在客户端里点开别人的战绩页是同一个接口，慢很多，每人只看 10 局）。不想让插件直接问 Riot 的服务器，
  在 `companion_config.json` 里加一行 `"direct_history": false`。想知道自己电脑上两种查法各用几秒：
  开着客户端运行 `Tuoz1Companion.exe --history-test`，结果在 `companion.log` 里。

- **彩蛋功能：头像墙**（v1.11.0）：勾选框下面有一行小字「彩蛋功能」，点一下，在另一个窗口里打开头像墙
  （用的是电脑自带的 Edge，没有就用 Chrome；两个都没有就打不开）。
  - 从客户端自带的五千多个头像里挑一个，点一下就换上。可以按名字或编号搜，按系列、年份筛，有收藏和最近用过。
  - 你有的头像，连账号头像一起换。你没有的头像，只改聊天资料里显示的那个：按参考的那个工具的说法，只有好友在好友列表和
    聊天资料卡上看得到，别处别人看到的还是你的账号头像（这一点没有实测过）。
  - 没拥有的头像是临时的，排队、选人、开局时客户端会把它改回去。插件开着的时候，发现被改回就再设一次，连着 3 次都被改回就停手。
    关掉头像墙的窗口不影响这个；下次打开插件也会接着重设。想停，在头像墙里点「换回我自己的头像」。
  - 这是插件里唯一会改你客户端里东西的地方（除了「自动接受对局」）。不点「彩蛋功能」，插件不会加载它，什么都不会改。
    这些都是 Riot 没有许可的用法，后果自负。它存的东西在配置文件夹的 `avatar_wall\` 里。

不想要窗口，加 `--no-gui` 只用命令行。这个模式下没有彩蛋功能的入口，之前挑过的头像也不会重设。

## 配置文件在哪

令牌和各种开关都存在 `companion_config.json` 里。从 v1.9.8 起它固定放在 `%APPDATA%\Tuoz1Companion\`（按 Win+R，输入 `%APPDATA%\Tuoz1Companion` 回车就能打开），不再和 exe 放在一起——所以把插件挪到别的文件夹不用重新输入令牌。从老版本更新上来的，第一次打开时会自动把 exe 旁边那份搬过去。

如果平时用的是普通账号、申请管理员权限时输的是另一个管理员账号的密码：配置放在平时登录的那个账号的文件夹里（v1.9.9 起；v1.9.8 时已经存到管理员账号那边的，接着用那一份）。

下文说「在 `companion_config.json` 里加一行」的，改的都是这个位置的文件；改完重开插件生效。日志 `companion.log` 还是在 exe 旁边。

（直接用 Python 运行源码时，配置文件还是和 `tuoz1_companion.py` 放在一起。）

## 桌面快捷方式

从 v1.9.6 起，第一次打开插件时会在桌面放一个快捷方式「托子的小警察」，以后从桌面打开就行。插件本体还在你下载到的那个文件夹里，别删它。

快捷方式每个位置只建一次：你自己删掉了不会再生成；把 exe 挪到别处再打开，桌面上那个会跟着改。不想要，在 `companion_config.json` 里加一行 `"desktop_shortcut": false`。

## 为什么打开时要管理员权限

从 v1.9.4 起，双击 exe 时 Windows 会弹一次确认框，点「是」就行。游戏通常是以管理员身份运行的，插件权限比它低的话，系统不让插件看到按键——对局里按住 Tab 看出装就没有反应。截图认海克斯、读等级这些不受影响，只有 Tab 这一样需要它。

点了「否」或者账号不是管理员，插件照常运行，只是 Tab 可能没反应。不想每次被问，在 `companion_config.json` 里加一行 `"run_as_admin": false`（或者启动时加 `--no-elevate`）。

## 常用参数

```bash
python tuoz1_companion.py --send-latest    # 启动后立刻把最近一场比赛上报一次（测试用）
python tuoz1_companion.py --reset          # 重新输入令牌
python tuoz1_companion.py --dump-dir dump  # 把上报的数据另存一份（排查问题用）
python tuoz1_companion.py --no-gui         # 不开窗口，只用命令行
python tuoz1_companion.py -v               # 详细日志
```

日志写在 exe（或源码）同目录的 `companion.log`。

## 批量导入黑名单

把 League Akari 导出的「标记玩家」JSON 直接拖到 `Tuoz1Companion.exe` 图标上（或 `python tuoz1_companion.py --import-blacklist 文件`）。插件通过已登录的客户端把 puuid 换成名字，列出你绑定过的服务器让你选，然后发给机器人存进黑名单。只有你是管理员的服务器才能导入；已经在黑名单里的人只更新备注，新名字每条约 1.3 秒。

从 v1.2.0 起插件会自动更新：自动下载替换并重启，配置和令牌不受影响。不想自动更新加 `--no-update`。

新版本平时从 GitHub 拿。有些电脑上插件连不上 GitHub（浏览器能上、插件不行），从 v1.12.0 起这种情况会改从机器人拿：
机器人把 GitHub 上最新的 exe 和它的签名清单转过来，插件用内置的公钥验过签名、核对过文件内容才会换上。
问不到 GitHub 的原因会写在窗口的日志里。如果日志里说「这台电脑暂时没法自动更新」，到
[Releases](https://github.com/juaijuii/Tuoz1Companion/releases/latest) 手动下载新版本换掉旧的就行。

什么时候检查新版本（v1.8.3 起）：启动时；每打完一局、战绩报完以后；闲着的时候每半小时一次。排到了等确认、选人、读条、对局中都不会更新，不会打断你。v1.8.2 及更早的版本是启动时和每 6 小时检查一次，想马上更新就关掉插件再打开。

## 工作原理

```
你的电脑                                        机器人服务器
┌───────────────┐   本机 HTTPS    ┌──────────────┐   HTTP POST   ┌──────────────┐
│ 英雄联盟客户端 │ ◄───────────── │ Tuoz1Companion│ ────────────► │  Tuoz1 Bot   │
│ (LCU API)     │  战绩 / 赛后统计 │               │               │ 分析 → 播报   │
└───────────────┘                 └──────────────┘               └──────────────┘
```

- 通过客户端进程的命令行参数（或 lockfile）拿到本机接口的端口和密码，和 LeagueAkari 等工具原理相同。
- 对局进行中记录 gameId，结束后读取 `/lol-match-history/v1/games/{gameId}` 拿完整战绩，
  并在结算阶段读取 `/lol-end-of-game/v1/eog-stats-block` 补上治疗队友、护盾队友等字段。
- 只上报比赛数据和当前账号的 puuid，令牌只用于向机器人证明"这是我"。
- 海克斯助手：海克斯大乱斗对局中，在卡片可能出现的时候（开局、你死亡后、刚升到解锁的等级），插件每 0.35 秒截一下三张卡片标题所在的那三小条，先在你自己的电脑上判断像不像卡片标题；
  像的时候（或者你按了热键）才去认上面的字。
  v1.9.0 起认字在你自己的电脑上完成（exe 里带着识别模型），截图不离开你的电脑；读条时插件会向机器人取一次你这个英雄的海克斯数据表，三选一时查这张表。
  只有本机认不了的时候（模型加载失败，或者用源码运行又没装那两个库），才把这三小条（灰度图，每条几 KB）发给机器人认，机器人不保存这些图。
  别的模式、别的时候不截图。不读游戏内存，不向游戏发送任何按键或点击。
- 使用统计（v1.8.1）：插件连机器人时会顺带报几个开关是开着还是关着（海克斯助手和它的三个细项、自动改无边框、十人战绩），
  只有开 / 关，没有别的内容；机器人主人用它看有多少人在用这些功能。

## 自己打包

正式发版不在本机打包：推一个 `v*` 的 tag，GitHub 会自动打包、自检、签名（`tools/sign_release.py`，
私钥是仓库的 Actions 密钥 `RELEASE_SIGNING_KEY`，作者电脑上有一份备份）并创建 Release。没有私钥的人打出来的包没有签名，
只能自己用，不能通过机器人分发。
